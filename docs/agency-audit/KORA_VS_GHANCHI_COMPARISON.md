## Not independently re-verified in this pass (mark as NEEDS FURTHER EVIDENCE)

- **Live hover computed-style values on Kora's actual button/nav elements.** Framer wraps visible text in nested `<span>`s (the same quirk called out for `navLink` in the base evidence file), so a fresh Playwright hover-and-read attempt during this audit returned the outer, unstyled wrapper's values (`background: rgba(0,0,0,0)`, `transform: none`) rather than the real styled element. The CSS-source comparison above (via `trial`, the verified recreation) is used instead, which is a reliable proxy since the component/CSS diff shows the interaction rules are otherwise byte-identical — but the exact Kora-live pixel values for button hover were not independently re-confirmed.
- **Fine-grained mobile-viewport visual comparison.** The mobile screenshots in `docs/agency-audit/evidence/screenshots/` are full-page captures (390×22,488px and 390×25,838px) rendered far below a legible scale by the image viewer; structural sectioning is visible but text/spacing detail is not verifiable at this resolution. A follow-up pass with per-section mobile crops is recommended before treating mobile as fully audited.
